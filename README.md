# fanqie.koplugin

KOReader 插件，用于在电纸书设备上阅读番茄小说。

## 功能特性

- 🔑 **扫码登录**：番茄网页扫码登录，自动获取书架/进度/目录，无需手动配置 Cookie
- 📚 **书架管理**：浏览番茄小说，支持封面显示、按最后阅读时间排序
- 📖 **章节阅读**：支持章节导航、自动翻页、目录自动跳转
- 🔄 **进度同步**：自动同步阅读进度到服务器（进入阅读拉取+阅读中定期上传+离开自动上传）
- ⚡ **预下载**：智能预下载后续章节，减少阅读等待（含限流保护，不阻塞阅读）
- 💬 **段评功能**：正文中显示段评数字气泡，点击查看段评详情（开关常驻设置页）
- 🔀 **多书源**：支持大灰狼、晴天、官方API 三个书源，自动检测可用线路
- 🎨 **界面优化**：适配墨水屏显示，纯黑白配色，无毛玻璃无平滑动画
- 📊 **阅读统计**：显示阅读进度（百分比/章节数）
- 📥 **批量下载**：支持下载全书，自动跳过已缓存章节，含限流等待
- 📋 **下载管理**：查看当前下载进度、取消任务、浏览历史记录
- 📶 **离线阅读**：书架和章节缓存持久化，无网络也可阅读已缓存内容
- 💾 **两层智能缓存**：书架/目录采用「内存主源 + 文件后备」策略，显示层零文件IO，刷新成功才更新缓存，失败保留旧数据
- ✨ **静默刷新**：进入阅读自动更新目录获取新章节，书架刷新动态更新内容无闪烁
- 🎛️ **操作菜单**：书架/目录左上角菜单图标，点击弹出操作选项（刷新书架/刷新目录）

## 安装方法

1. 下载插件压缩包（从 GitHub Releases 页面）
2. 将 `fanqie.koplugin` 文件夹复制到 KOReader 的 `plugins/` 目录
3. 重启 KOReader
4. 在菜单中找到「番茄书架」入口
5. 首次使用扫码登录（菜单 → 番茄小说 → 扫码登录），用番茄小说 App 扫码即可

## 书源说明

本插件支持三个书源，按优先级从高到低排列：

| 书源 | 说明 | 排序 |
|------|------|------|
| **大灰狼** | 聚合平台，支持番茄/七猫/塔读/QQ阅读等底层源，支持段评 | 1（默认首选） |
| **晴天** | 聚合平台，支持番茄底层源 | 2（备用） |
| **官方API** | 番茄官方接口，需扫码登录 | 3（备用） |

插件会按排序依次尝试可用书源。大灰狼排第一位，获取正文失败时自动回退到晴天，再回退到官方API。

## 番茄官方扫码登录

番茄官方书源（书架/目录/进度）通过扫码登录获取 Cookie，**无需手动复制粘贴 Cookie 字符串**。

### 登录步骤

1. 菜单 → 番茄小说 → 扫码登录
2. 屏幕显示二维码
3. 打开手机番茄小说 App，扫描屏幕上的二维码
4. 在 App 中确认登录
5. 登录成功后 Cookie 自动持久化，重启 KOReader 也无需重新登录

### Cookie 过期

- Cookie 有效期较长（通常 60 天），过期后会提示重新登录
- 重新扫码即可，无需任何手动操作

### 手动 Cookie 保底（可选）

扫码登录是首选方式。如无法扫码（如设备无摄像头/网络受限），可手动填写 Cookie 作为 fallback：

- 在 `config.lua` 的 `cookie_string` 填入完整 Cookie 字符串，或在 `cookies` 表里填入 `ttwid` / `sessionid` 等键值
- **优先级**：扫码 Cookie > `cookie_string` > `cookies` 表。已扫码登录后，手动配置不会覆盖扫码结果
- 清空扫码 Cookie（退出登录）后，手动配置自动生效

> **说明**：扫码登录在子进程中执行网络请求，UI 不卡顿；二维码显示期间可随时取消。

## 大灰狼书源配置

### 第一步：注册账号

1. 浏览器访问 `https://v2.czyl.cf`（大灰狼官网）
2. 注册账号（邮箱 + 密码）
3. 注册成功后，将账号密码填入 `config.lua`

### 第二步：填写配置

编辑 `config.lua`，找到 `dahuilang` 配置段：

```lua
dahuilang = {
    server_url = "https://v2.czyl.cf",
    servers = {
        "https://v2.czyl.cf",
        "https://v4.czyl.cf",
        "https://v5.czyl.cf",
    },
    username = "你的邮箱@example.com",  -- ← 填入注册邮箱
    password = "你的密码",              -- ← 填入密码
    auto_login = true,                  -- token过期自动重新登录
    source = "番茄",                    -- 底层书源
},
```

### 第三步：在 KOReader 中登录

1. 打开 KOReader → 菜单 → 番茄小说 → 设置 → 书源管理
2. 点击「大灰狼」
3. 点击「检测可用线路」— 自动检测最快可用服务器
4. 点击「未登录 (点击立即登录)」— 自动登录并获取 token
5. 登录成功后即可使用

> **提示**：`auto_login = true` 时，token 过期会自动重新登录，无需手动干预。

## 配置说明

v2.1.1 起支持扫码登录，**番茄官方书源无需手动配置 Cookie**——菜单 → 番茄小说 → 扫码登录，用番茄小说 App 扫码即可，Cookie 自动获取并持久化。

如需使用大灰狼/晴天聚合书源，将 `config.example.lua` 复制一份改名为 `config.lua`，填入账号信息：

```lua
return {
    -- 大灰狼书源配置（推荐首选）
    dahuilang = {
        server_url = "https://v2.czyl.cf",
        servers = {
            "https://v2.czyl.cf",
            "https://v4.czyl.cf",
            "https://v5.czyl.cf",
        },
        username = "",          -- 注册邮箱
        password = "",          -- 密码
        key = "",               -- 密钥（可选，优先于账号密码）
        auto_login = true,      -- token过期自动登录
        source = "番茄",        -- 底层书源
    },

    -- 晴天书源配置（备用）
    qingtian = {
        server_url = "https://v1.gyks.cf/",
        servers = {
            "https://v1.gyks.cf",
            "https://v2.gyks.cf",
            "https://v3.gyks.cf",
        },
        username = "",
        password = "",
        auto_login = true,
    },

    -- 进度同步
    sync = {
        pull_on_open = true,       -- 打开书籍时拉取云端进度
        upload_on_close = true,    -- 关闭书籍时上传进度
    },

    -- 缓存设置
    cache = {
        download_book_images = true,
        pre_download_chapters = 3,  -- 预下载章节数
    },
}
```

## 使用指南

### 首次使用

1. **安装插件**：将 `fanqie.koplugin` 放入 KOReader 的 `plugins/` 目录
2. **重启 KOReader**
3. **扫码登录**：菜单 → 番茄小说 → 扫码登录，用番茄小说 App 扫描二维码
4. **进入书架**：登录成功后，菜单 → 番茄小说 → 书架

### 书源管理

路径：菜单 → 番茄小说 → 设置 → 书源管理

- **启用/禁用**：点击书源名称，选择「禁用此源」或「启用此源」
- **检测线路**：点击「检测可用线路」，自动选择最快服务器
- **登录/退出**：点击「未登录 (点击立即登录)」登录，或点击「已登录 (点击退出)」退出

### 书架操作

- **点击书籍**：打开书籍详情页面
- **左上角菜单图标**：点击弹出操作菜单（刷新书架），刷新时动态更新内容无闪烁
- **长按书籍**：显示操作菜单（开始阅读、章节目录、清空缓存）
- **排序**：默认按最后阅读时间排序

### 阅读操作

- **点击左侧**：上一页
- **点击右侧**：下一页
- **点击中间**：打开菜单
- **章节开头向前翻页**：自动跳转到上一章
- **章节结尾向后翻页**：自动跳转到下一章

### 段评功能

1. **开启段评**：菜单 → 番茄小说 → 设置 → 段评显示（持久开关，重启后保持状态）
2. **查看段评**：正文中看到段评数字（如 `47`），点击即可查看段评详情
3. **段评详情**：使用可滚动界面展示全部评论，支持上一段/下一段切换
4. **关闭段评**：菜单 → 番茄小说 → 设置 → 段评显示（再次点击切换）
5. **重新获取本章节**：段评开启后，点击「重新获取本章节」会带段评数据重新下载当前章节

> **注意**：段评功能仅大灰狼书源支持。

### 目录操作

- **打开目录**：自动跳转到当前阅读章节所在页面，进入阅读时静默刷新获取新章节
- **点击章节**：跳转到对应章节
- **左上角菜单图标**：点击弹出操作菜单（刷新目录），保持当前页码
- **缓存标记**：已下载的章节显示 ✓ 标记

### 下载管理

路径：菜单 → 番茄小说 → 下载管理

- **查看进度**：当前下载任务显示实时进度条和章节信息
- **取消下载**：点击「取消下载」可中止当前任务
- **后台运行**：下载进度对话框可关闭，下载在后台继续
- **历史记录**：显示最近 10 条下载记录（完成/中断/取消）
- **清空历史**：点击「清空历史记录」清除所有历史

> **说明**：下载状态持久化到本地，即使 KOReader 退出重启，历史记录依然保留。未完成的下载会标记为「中断」。

### 离线阅读

- **书架离线**：书架数据自动缓存，无网络时显示缓存内容，刷新失败保留旧数据
- **章节离线**：已下载的章节无网络也可阅读
- **自动定位**：离线打开书籍时，从上次阅读的章节开始（书架数据中的进度）
- **两层缓存**：内存主源 + 文件后备，重复显示书架/目录零文件IO，Kindle弱设备流畅运行
- **智能回退**：Cookie过期/网络失败时自动回退到文件缓存，不丢失已有数据

## 常见问题

### Q: 书架显示为空？

A: 请检查是否已扫码登录。菜单 → 番茄小说 → 扫码登录，用番茄小说 App 扫码。Cookie 过期会提示重新登录，重新扫码即可。

### Q: 章节内容获取失败？

A: 可能是书源服务器不可用。请进入「书源管理」→「检测可用线路」切换服务器，或尝试登录其他书源。

### Q: 段评不显示？

A: 段评功能仅大灰狼书源支持。请确保：1) 大灰狼书源已启用并登录；2) 菜单 → 番茄小说 → 设置 → 「段评显示」开关已开启；3) 点击「重新获取本章节」带段评数据重新下载当前章节。

### Q: 点击段评数字没反应？

A: 请确保已更新到最新版本，并重启 KOReader 使补丁生效。

### Q: 阅读进度不同步？

A: 请确保网络连接正常，进度同步需要网络支持。进度同步策略：进入阅读自动拉取云端进度，阅读中定期上传，离开书籍自动上传。

### Q: 封面不显示？

A: 封面是异步下载的，首次打开书架时需要等待一段时间。如果长时间不显示，请检查网络连接。

### Q: 书架/目录刷新后数据没变？

A: v2.2.0 采用「刷新成功才更新缓存」策略。如果网络失败/Cookie过期，会保留旧缓存并提示"刷新失败，显示缓存数据"。请确保网络正常且Cookie未过期，再点击左上角菜单图标 → 刷新。
